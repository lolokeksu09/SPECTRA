# SPECTRA — project context

## Подтверждённые решения

- Назначение: нативный Android-клиент мониторинга устройства с интерактивной 3D-моделью телефона.
- Основное устройство владельца: **белый Lenovo Legion Y70 2026** с установленной Motorola-портированной прошивкой Android 16. Цвет 3D-пресета по умолчанию — **белый**. Чёрный вариант доступен дополнительно и выбор запоминается локально.
- Внешний вид основан на предоставленных 28 октября 2026 изображениях: прямые грани, передняя камера по центру, блок 2×2 с тремя объективами и вспышкой. Нельзя считать иллюстрации точным CAD, измеренным тепловым полем или доказательством расположения внутренних компонентов.
- `Build.MODEL` и `Build.MANUFACTURER` показывают именно то, что сообщает прошивка, независимо от визуального пресета.
- Без root, без выдуманных метрик CPU/GPU/FPS, без обязательного интернета и скрытой телеметрии.
- Менять только `lolokeksu09/SPECTRA`; другие проекты не затрагивать.
- Доставка: GitHub Actions `Android APK` — отладочный APK в Artifacts и prerelease Releases после успеха `main`. Это не release-подпись.
