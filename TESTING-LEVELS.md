# SPECTRA — L1–L5

Адаптация пользовательского архива **Project-Workflow-Standard v1.3**. Названия уровней — соглашение проекта, не универсальная отраслeвая классификация.

| Уровень | Назначение | Подтверждение |
| --- | --- | --- |
| L1 | Корректность исходников и конфигурации | Синтаксис, компиляция и применимые статические проверки |
| L2 | Поведение изменённого модуля | `testDebugUnitTest`: валидация отсутствующих датчиков, корректный выбор цвета/неизвестный ID |
| L3 | Межмодульный путь UI → состояние → GL | На эмуляторе или устройстве: выбор цвета, сохранение после рестарта, поворот, масштабирование, жизненный цикл |
| L4 | Полная сборка на указанном SHA | GitHub `Android APK` успешно выполнил `testDebugUnitTest assembleDebug`, APK доступен |
| L5 | Работа доставленного APK | Установка именно того APK на Legion Y70, просмотр белого/чёрного корпуса и проверка реальной телеметрии |

Оценивай уровни по реально выполненным сценариям; `skipped`, `pending` и отсутствие устройства не являются успехом. Для L4 указывай точные SHA и URL запуска. L4 не подтверждает L3 или L5. При изменении CI проверяй фактическую CI-job. Не ослабляй проверки ради зелёного статуса.
